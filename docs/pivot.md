# App Pivot: Run for Fun 🏃

## Overview

The app is being rebranded from **Earn Your Beers** to **Run for Fun** to ensure App Store compliance and broaden the appeal.

## Key Changes

### 1. Multiple Reward Categories
Instead of focusing solely on beer/pints, users can choose their reward type:

| Reward Type | Example Rewards | 5km Earns |
|-------------|-----------------|-----------|
| 🍺 **Pints** | Beer, cocktails | 1 pint |
| 🍰 **Treats** | Desserts, snacks | 1 treat |
| 🎮 **Gaming** | Game time, sessions | 30 min |

### 2. Neutral Language
- "Earn" → reward-agnostic terminology
- No alcohol-specific branding in public-facing content
- User chooses their "reward currency" at onboarding

### 3. App Store Compliance
The pivot addresses potential rejection concerns:
- No promotion of alcohol consumption
- Framed as a fitness motivation tool
- Rewards are customizable (gaming-friendly option)

## Implementation Phases

1. **Phase 1**: Add reward type selection to onboarding
2. **Phase 2**: Update UI to show selected reward type
3. **Phase 3**: Rename app and update branding
4. **Phase 4**: Update App Store listing

## Internal vs External Naming
- **External**: "Run for Fun" (App Store, marketing)
- **Internal**: codebase can retain current naming during transition
