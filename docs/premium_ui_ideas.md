# Premium UI Ideas

This document serves as a backlog for high-effort, high-impact UI/UX improvements to be considered after the MVP (Stage 1) is solid.

## navigation
### 1. The "Date Strip" (Weekly History)
Instead of simple arrows, implement a horizontal date picker/strip at the top of the dashboard.
- **Visual**: A scrollable horizontal list of weeks or days.
- **Interaction**:
    - Tap a week to jump to it.
    - Active week is highlighted (pill shape or bold text).
    - Smooth snapping animation.
    - "Today" button to jump back to index 0.

## Animations
### 2. 3D "Cuboid" Item Rotation
(Previously implemented, then simplified).
- **Concept**: When adding/removing items, use a true 3D rotation where the new item rotates in from the "back" of the card like a cuboid face, rather than just sliding or fading.
- **Impact**: Adds a very tactile, physical feel to data entry.

## Visuals
### 3. Dynamic Backgrounds
- Change the app background subtly based on performance (e.g., slight red tint if in debt, golden tint if in credit).
- Or time of day (Day/Night mode).

### 4. Confetti / Particles
- Trigger a particle explosion (beer bubbles?) when the user gets "Square" or reaches a milestone.
